# Layered artwork

Decide character/object, title, subtitle, action/effect, art medium, palette and card aspect from the user. State assumptions only where they matter. Preserve reference identity when requested; do not invent text that claims official affiliation.

Use a shared portrait canvas, normally 1024×1536. Reserve roughly the top 15% and bottom 15% for typography. Keep a complete readable silhouette. Generate the layers separately:

1. Subject: requested subject/action, accurate anatomy and defining details, bold readable contours, genuinely transparent RGBA PNG. No border, text, background, checkerboard or baked full-card layout. Retain alpha from the image tool.
2. Background: complementary atmosphere and motifs, full opaque canvas, quieter central field and typography zones. Foil is generated by the material; restrained flecks in the painting are acceptable, but don't bake all holographic effects into the picture.
3. Line art: edit the selected subject image, same canvas and exact pose/placement, simplified single black contour strokes, white background, no hatching or filled silhouettes. Inspect registration before use. Do not derive a drifting new pose from a text-only description.
4. Text: exact title/subtitle/technique and edition. Prefer real fonts rendered to transparent PNG for names and Chinese text. Keep high contrast and leave spacing for descenders/brush strokes. The supplied typography script is optional; choose appropriate fonts and hierarchy for the user's language/style.

When the image tool returns a purported cutout, inspect alpha numerically and visually. Some outputs paint a checkerboard into RGB. Reject that revision instead of feeding it into an alpha shader. Never assume a PNG has alpha merely from its extension.

Reference roles must be explicit: identity reference, style reference, edit target, or background. Keep each target invariant during revisions. Write the actual prompt set into the output project's provenance notes, not this skill repository.
